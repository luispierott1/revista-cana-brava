# Cana Brava

Site da Revista Cana Brava: política, poder e bastidores de Campos dos Goytacazes.

- **Site:** a capa (`index.html`) lista os artigos de `data/artigos.json`.
- **Artigos:** cada um fica em `artigos/<endereco>/`, com a página (`index.html`), os dados para edição (`artigo.json`) e as imagens.
- **Editor:** `editor/`. Ele publica direto neste repositório pela API do GitHub, usando uma chave de acesso salva só no navegador de quem publica.

Não edite `data/artigos.json` nem as pastas de `artigos/` à mão: use o editor.
